# PLATAFORMA Academia Yudan 🎓

¡Bienvenido a **Academia Yudan**, la plataforma estudiantil de estudiantes del CESDE! Actualmente, el proyecto se encuentra **en construcción** 🏗️, desarrollando un entorno intuitivo, moderno y eficiente para estudiantes y docentes.

---

## 🚀 Sobre el Proyecto

**Academia Yudan** nace con el objetivo de centralizar y facilitar los procesos académicos esenciales en un solo lugar. Busca resolver la fragmentación de herramientas actuales ofreciendo una interfaz limpia y un rendimiento optimizado.

### ✨ Funcionalidades Planeadas (En Desarrollo)
*   **Gestión Académica:** Consulta de asignaturas, horarios y asistencias en tiempo real.
*   **Seguimiento de Notas:** Visualización detallada de calificaciones por periodos (momentos).
*   **Calendario Escolar:** Recordatorios automáticos de entregas, exámenes y eventos.
*   **Comunicación Directa:** Canal de contacto integrado entre la comunidad educativa.

---

## 🛠️ Tecnologías Utilizadas

El stack tecnológico seleccionado para este proyecto incluye:

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Control de Versiones:** Git y GitHub para la colaboración

## 💻 Configuración Local e Instalación

Sigue estos pasos para montar el entorno de desarrollo en tu máquina:

### 1. Clonar el repositorio
Abre tu terminal y ejecuta el siguiente comando:
```bash
git clone (https://github.com/jsmedinamusic-cyber)
```

### 2. Ingresar al directorio
```bash
cd primermomento
```

### 3. Visualizar el proyecto
Al estar en fase inicial de maquetación, puedes abrir el archivo principal (`index.html`) directamente en tu navegador o utilizar la extensión **Live Server** en VS Code para ver los cambios en tiempo real.
